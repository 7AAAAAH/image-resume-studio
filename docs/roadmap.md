# 开发计划 / Roadmap

> 目标：把"图片复刻简历"从一次性的排版技巧，做成可维护、可扩展、可被社区复用的开源引擎。

## 1. 产品原则

1. **本地优先**：默认不上传简历，不需要账号。
2. **双击即用**：核心版本保持零构建、零依赖、离线可打开。
3. **还原优先于模板数量**：先做到"像原图"，再谈模板市场。
4. **一页 A4 是硬指标**：任何改动都不能破坏单页与打印一致性。
5. **中文优先**：字体度量、标点、日期格式、信息密度按中文简历打磨。

## 2. 现状盘点（v0.1）

已具备：

- 图片上传、主色提取、按宽高比匹配版式；
- 浏览器 OCR + 人工校对；
- 四种版式、主色 / 密度 / 页边距 / 头部轮廓调节；
- 实时预览、页面占用率、一键压缩到一页；
- PDF（浏览器打印）、独立 HTML、JSON 导出与 JSON 导入；
- localStorage 自动保存。

主要技术债：

- `app.js` 单文件约 61KB，状态、渲染、导入、导出、OCR 混在一起；
- 版式识别只看宽高比，无法识别卡片、分栏、圆角等结构；
- OCR 依赖 CDN，离线不可用；
- 独立 HTML 导出的图片是绝对路径；
- 无自动化测试、无 lint、无 CI；
- 无数据 schema、无版本迁移；
- 编辑器缺少拖拽、撤销、快捷键、行内编辑。

## 3. 版本规划

### v0.2 可维护（第 1-2 周）

**主题：让项目像一个正经开源项目。**

**进度（2026-10-28）**：源码拆分、构建脚本、单元测试、CDP 冒烟测试、CI、独立 HTML 图片内联、弹窗可访问性、启发式版式分析（头部高度 / 圆角 / 侧栏 / 置信度）、模板 DSL 导入导出已完成。离线 OCR 与更完整的浏览器矩阵测试待做。

| 任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 仓库工程化 | LICENSE、README、CONTRIBUTING、Issue/PR 模板 | 新访客 3 分钟内能跑起来 |
| 模块拆分 | `js/state.js`、`render.js`、`editor.js`、`import.js`、`export.js`、`ocr.js`、`presets.js` | 不引入构建工具仍可直接打开 |
| 单元测试 | `parseResumeText`、`normalizeData`、`autoFit` | 覆盖率 ≥ 60% |
| 端到端测试 | Playwright：加载 / 编辑 / 切版式 / 导出 JSON / 打印 | CI 全绿 |
| 离线 OCR | 本地 worker + 可选语言包 | 断网时可识别中文 |
| 导出修复 | 图片内联 data URL | 导出 HTML 换机后仍可显示 |
| 可访问性 | label、焦点、键盘操作 | Lighthouse A11y ≥ 90 |
| 部署 | GitHub Pages + Actions | 推送 main 自动发布 |

**风险**：拆模块时容易破坏"直接打开"能力。缓解：用原生 ES Modules，并通过 `file://` 实测。

### v0.3 真正理解版式（第 3-6 周）

**主题：从"猜模板"升级为"读版面"。**

**进度（2026-10-28）**：模板 DSL、模板导入导出、可选 BYOK 视觉模型适配层（OpenAI / OpenAI 兼容接口 / Claude）已完成 alpha。模板编辑器与撤销/重做继续推进。

| 任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 版面 DSL | `schema/template.schema.json` + 文档 | 可描述头部、分栏、卡片、圆角、间距、字体 |
| 视觉模型适配层 | `js/vision/openai.js`、`claude.js`、`qwen.js`、`glm.js` | BYOK，失败自动回退 |
| 版式解析 | 图片 → DSL + 置信度 + 区域标注 | 10 张测试图，主色误差 ΔE < 8 |
| 模板编辑器 | 区域拖拽、token 面板、撤销/重做 | 5 分钟内改出一套新模板 |
| 模板导入导出 | `.resume-template.json` | 跨设备可复现 |
| 多页支持 | 分页规则 + 断点控制 | 内容超长时无截断、无重叠 |
| 头像工具 | 裁剪、圆角、背景移除 | 导出 PDF 无锯齿 |

**关键决策**：视觉模型只输出 DSL，不直接生成 HTML。HTML 由本地渲染器生成，保证可预测、可测试、可回退。

### v0.4 求职闭环（第 7-10 周）

**主题：从"排得好看"到"投得出去"。**

| 任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| JD 匹配 | 关键词覆盖表 + 缺口 + 改写建议 | 支持粘贴 JD / 上传截图 |
| ATS 检查 | 规则引擎 + 评分 + 修复建议 | 覆盖字体、表格、图片、联系方式 |
| PDF / DOCX 导入 | 解析为内部 schema | 常见单页简历解析成功率 ≥ 85% |
| DOCX 导出 | 可编辑 Word 版本 | 版式与 PDF 基本一致 |
| 内容助手 | STAR 改写、量化建议 | 不改变事实，仅优化表达 |
| 多简历管理 | 主简历 + 派生版本 + 历史 | 可对比差异、一键回滚 |

### v1.0 可分发（第 11-14 周）

**主题：从项目变成生态。**

- 模板市场：提交、审核、评分、一键应用；
- 浏览器扩展：从招聘页抓取 JD；
- 插件 API / Web Component；
- 分享链接与二维码（可选云端，默认关闭）；
- 校招 / 团队版；
- 完整中文文档站与视频教程。

## 6. 指标

产品指标：

- 图片导入到生成简历的中位耗时（目标 < 60 秒）；
- OCR 校对后字段准确率（目标 ≥ 95%）；
- 一页适配成功率（目标 ≥ 90%）；
- 导出后用户手动修改次数（越低越好）。

工程指标：

- 核心包 gzip 体积（目标 < 150KB）；
- 首屏时间（本地 < 1s）；
- 测试覆盖率（目标 ≥ 60%）；
- CI 平均时长（目标 < 3 分钟）。

社区指标：

- Issue 首次响应时间（< 48h）；
- 外部 PR 合并率；
- 模板贡献数量。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 视觉模型输出不稳定 | 版式还原失败 | 只输出 DSL，本地渲染；置信度低时回退启发式 |
| 中文 OCR 准确率不足 | 用户不信任 | 强制校对步骤；提供字段级高亮 |
| 浏览器打印差异 | PDF 版式漂移 | 固定画布 + 多浏览器快照测试 |
| 范围膨胀 | 无法交付 | 每个版本只做一条主线，ATS/JD 延后 |
| 隐私争议 | 口碑受损 | 默认本地、明示 CDN、提供离线包 |
| 商业化压力 | 偏离开源 | open-core，核心永久 MIT |

## 8. 暂不做

- 账号体系与云同步（v1.0 前不做）；
- 在线支付；
- 移动端原生 App；
- 多人实时协作；
- 自建 OCR 模型训练。
